A terminal dashboard that finds the servers you start in any terminal, editor or agent, groups them by project, and stops them when you ask. It never starts anything, never touches your shell, and has no network code.

# how it works

    
    
    
      
  1. discovery. Every two seconds Paddock asks lsof (netstat on Windows) who listens on which port, and the process table who started them. A listener counts when it is yours and runs below your home folder.
    2. 
      
  2. one process tree is one server. yarn dev and the sh, vite and esbuild under it are one server called dev. Your shell, editor, terminal or coding agent is never part of a server.
    3. 
      
  3. stop and kill. x sends SIGTERM to the whole tree and SIGKILL after five seconds; K kills at once. Each asks first, and Paddock checks the process is still the one you saw.

Keys

      
↑ ↓  k jmove
tabservers / ports
enterport → its server
oopen in the browser
ycopy its URL
Ycopy its command
xstop: SIGTERM, SIGKILL after 5 s
Kkill it now
,settings: theme, keys, splash
?help
qquit

      
Every key can be rebound in settings (,) or in ~/.config/paddock/config.toml.

# what paddock never does

    
    
      
  • ✗ start, restart or wrap your commands
    • 
      
  • ✗ add shell functions, aliases or PATH changes
    • 
      
  • ✗ stop anything you did not confirm
    • 
      
  • ✗ open a network connection or send telemetry
    • 
    

    
A CI scan fails the build if network code is ever added.
